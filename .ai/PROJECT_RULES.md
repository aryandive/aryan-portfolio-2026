# Engineering Constraints & Rules
- **Identity:** The developer is a Full Stack Engineer and ECE student. The portfolio must bridge Hardware (ESP32, C/C++) and Cloud SaaS (Next.js, PostgreSQL).
- **Stack:** Next.js 15 (App Router), TypeScript (Strict Mode), Tailwind CSS, Drizzle ORM, Neon DB.
- **Data Flow:** React Server Components (RSCs) MUST be used for data fetching. Zero client-side JS for initial loads.
- **Workflow:** Strictly follow PLAN → BUILD → TEST → REVIEW. Never write implementation code before architecture is approved.
- **Tone:** Technical, concise, and definitive. No generic placeholder text; use actual project references (SyncFlowState, WorkStation, Agri-AI).
